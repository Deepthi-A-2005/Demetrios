# Demetrios Android app

React 19 + Vite 7 + Tailwind 4 UI, packaged for Android with Capacitor 7.

- App name: **Demetrios** · Package ID: `com.demetrios.fieldrover`
- Web UI source: `client/src/` · Native project: `android/` (generated by Capacitor)

```bash
npm install
npm run dev          # browser preview at http://localhost:3000
npm run check        # TypeScript check
npm run build        # production web build -> dist/
npm run cap:sync     # build + copy into android/
npm run cap:open     # open Android Studio
```

Requirements for building the APK: Node 20+, JDK 21, Android Studio (SDK 35).
After changing the UI, always run `npm run cap:sync` before building again.
